# Retired local prompt route

These files belonged to the former local generation path where a free-form
prompt could trigger web research or an AI director before notes were created.

They were removed from the local material-first route on 2026-08-10.  They are
kept here only as recoverable history and must not be imported by the desktop
engine or listed in `PLG.spec`.

`beat_planner.py` is intentionally not in this archive: it is still used by
the separate cloud service and is outside the local MIDI route.
