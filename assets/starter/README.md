# PLG Starter Sounds (bundled)

**Included with PLG** — no download required.

Every sound here is generated by PLG's own synthesis code (`math` plus
`random` with fixed seeds). Nothing in this folder comes from a sample pack,
a preset library, or any other third-party audio.

| File | Channel |
|------|---------|
| `PLG_starter_kick.wav` | PLG Kick |
| `PLG_starter_808_bass.wav` | PLG 808 Bass |
| `PLG_starter_hat.wav` | PLG Hi-Hats |
| `PLG_starter_clap.wav` | PLG Clap |
| `PLG_starter_snare.wav` | PLG Snare |
| `PLG_starter_melody.wav` | PLG MIDI (melody) |

(`PLG_starter_808.wav` is the older single-808 asset. There is no "PLG Sub 808"
channel — `808_bass` is the only low-end lane.)

`bundled_sounds/` holds 16 further one-shots from the same generators; PLG
picks from that pool by prompt keyword before falling back to the files above.

Generate → the app opens FL Studio with these loaded.

> **Known limitation.** The bundled 808 is short enough that
> `library_quality.bass_808_tail_rejection_reason` rejects it for sustained or
> transposed 808 lines. When the user library is empty or unreachable, the
> `808_bass` lane is dropped and the export is blocked. See `KNOWN_ISSUES.md`.

## Regenerating

These WAVs are gitignored, so a clean checkout has none of them. They are
rebuilt from tracked source — `PLG.spec` does it automatically before
packaging, and it can be run by hand:

```
python tools/build_starter_assets.py            # generate what is missing
python tools/build_starter_assets.py --check    # verify, write nothing
```

`GENERATED.json` records, for all 23 shipping WAVs, which generator produces
each one and the SHA256 it must have. Generation is deterministic and
idempotent: the same source always yields the same bytes.

## Retired: the optional CC0 upgrade

PLG used to accept third-party sample packs here: you downloaded three zips
by hand, dropped them into `incoming/`, and an installer copied WAVs out of
them over the starter files above. That path was retired on 2026-08-27. The
starter audio is first-party only, and `incoming/` is no longer read.

Installs that went through the old path keep whatever files they already
have -- nothing rewrites or deletes them, so their sound is unchanged. They
report `"source": "signature_sounds_cc0"` in `starter_manifest.json`.

This is unrelated to `assets/starter/PLG_Samples/`, the commercial melodic
pool dropped from the shipping bundle on 2026-08-27 (`KNOWN_ISSUES.md`
§0af). That folder may still exist in a dev checkout, but no build
carries it.
